## Overview
The "Delete Campaign" endpoint allows users to remove an existing AI-driven calling campaign from Toingg. By sending a DELETE request to the `/delete_campaign/{id}` endpoint, users can specify the campaign ID they wish to delete. This operation is irreversible and will permanently remove the campaign and its associated data from the system.
